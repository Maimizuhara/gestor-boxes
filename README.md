# Gestor de Boxes - Prototipo PHP + MySQL (XAMPP)

## Instalacion en XAMPP
1. Copia la carpeta `gestor_boxes` dentro de `C:\xampp\htdocs\gestor_boxes`.
2. Inicia **Apache** y **MySQL** desde el Panel de Control de XAMPP.
3. Abre `http://localhost/phpmyadmin`, crea la base de datos `gestor_boxes` e importa `database/gestor_boxes.sql`.
4. Accede a `http://localhost/gestor_boxes`.
5. Contraseña inicial de prueba para todas las cuentas: `Box2026!`.
